## Confirmed defects and changes

The new regression tests were run against `c8258b6` before changing production
code. They reproduced these problems:

- `decode` ignored `match.fps`, so its 0.6-second dwell used 15 observations at
  10, 25, and 50 fps. It now uses the match rate: 6, 15, and 30 observations.
  An explicitly supplied `state_machine.fps` must agree with the match. The
  config fallback remains for Belek's legacy fixtures without a `fps` field.
- `round(seconds * fps)` could undershoot the required support count; 0.1
  seconds at 25 fps became 2 observations. It now uses `ceil`, as proposed in
  the validation plan and used by E3, giving 3 observations. This is a count
  convention, not a promise of elapsed-time continuity across missing frames.
- Independently valid contracts could refer to different timeline lengths.
  A one-frame FeatureData could silently broadcast across a longer match;
  other mismatches produced opaque NumPy errors. E2 now checks every consumed
  array's shape and the feature/match frame axes before fusion.
- Finite but out-of-range score thresholds and weights were accepted. E2 now
  rejects values outside their documented [0,1] range with the setting name.

The shared function signature and dataclass fields are unchanged. Default
25-fps output is unchanged on these scenarios. Fractional dwell settings and
non-25-fps matches deliberately change; contradictory fps config now fails.
E1/E3/E4/E5 should review these config/alignment expectations when integrating.

## Boundary measurements

The following table is generated by `python -m tests.e2_scenarios` with the
unchanged default thresholds: team dwell 0.60 seconds, stop dwell 0.08 seconds,
25 fps. Inputs have strong unambiguous team/stop support except where the case
explicitly inserts missing evidence. Each case has a 30-frame establishment
period excluded from event matching.

Boundaries are read directly from labels, independently of decoder diagnostics.
Generated events have unique `(from,to)` types within each case; match those
types without a time tolerance to expose long delays. Missing and spurious
events are counted separately. This is not the official transition score.
The causal decoder places labels at confirmation, so decision delay equals
final boundary error. Positive values mean late. At 25 fps, 14 frames is 0.56
seconds; the first supporting observation counts toward the 15-observation dwell.

|---|---|---|---|
| Turnover | +14 | 0 | 0 |
| Stop | +1 | 0 | 0 |
| Restart | +14 | 0 | 0 |
| Same-team restart | +1, +14 | 0 | 0 |
| Turnover with 100-frame gap | +114 | 0 | 0 |
| 14-frame A possession | — | 2 | 0 |
| 15-frame A possession | +14, +14 | 0 | 0 |
| 16-frame A possession | +14, +14 | 0 | 0 |

Direct stop inputs already contain decisive evidence, so the +1-frame stop
delay above excludes E3's confirmation delay. A separate invented geometric
case runs `build_priors -> decode -> write_submission`: outside/still starts at
frame 30, E3 rejects the initial jump and confirms at 45, E2 calls D at 46.
The same-team restart has team support from 60 and is called at 74. The test
checks both exact transitions, repeatable CSV bytes, and the unchanged official
validator with `--rows 100`. E4 feature extraction and E5 pipeline wiring are
still absent; this is a synthetic module-integration slice, not a complete run.

The unchanged official scorer is also exercised on small invented perfect,
abstention-gap, and same-team-stop examples. Those tests verify metric usage;
they are not evidence about hidden-match performance.

## Policy findings requiring review

1. **Sub-dwell possessions are lost.** Fourteen perfect A observations between
   H runs never establish A. Fifteen observations do, but the A interval is
   shifted 14 frames later. Stronger versions of the same already-decisive
   evidence cannot change this threshold. This is a known limitation, not a
   claim that every short run is a deflection.
2. **Pending support never expires.** Fourteen A observations, 1,000 neutral
   frames, then one A observation switch H to A immediately on that last
   observation. An incumbent or different decisive candidate cancels pending
   support; neutral evidence does not. This follows Belek's pause policy but
   can combine unrelated observations across arbitrarily long gaps.
3. **Unknown-team restarts remain D.** After a confirmed stop, reliable live
   support and restart evidence without a team cannot exit D. Team evidence
   must later earn its whole dwell. The schema has no separate live-unknown
   state; E2/E3/E4 must agree on a hold/abstain/team policy before changing it.
4. **Initial D is a prior, not observed truth.** All-neutral graded sequences
   stay D. The tests characterize the existing initialization and do not prove
   that a half begins stopped or that missing observations imply a stop.

Automatic backdating is not enabled. For an uninterrupted, correctly identified
transition, placing the boundary at the first supporting observation would
remove these 14 frames of delay. But backdating to stale support across a long
gap can rewrite a large interval with no evidence, and cannot recover a
sub-dwell possession that never confirms. A bounded correction experiment needs
separate evidence-start and confirmation indices, an explicit gap limit, and
tests protecting confirmed stops and half boundaries. These tests and the
timing report provide the baseline for that experiment.
